1. Constraint Programming

Constraint Satisfaction Problem (CSP)

The Constraint Satisfaction Problem (CSP) is defined by:

  • a set of variables X={x1,x2,…,xn}X = \{x_1, x_2, \ldots, x_n\} X={x1​,x2​,…,xn​}
  • each with a domain D={d1,d2,…,dn}D=\{d_1,d_2,\dots,d_n\}D={d1​,d2​,…,dn​} of possible values
  • and a set of constraints C={c1,c2,…,cm}C = \{c_1, c_2, \ldots, c_m\}C={c1​,c2​,…,cm​}
    • where each constraint ci=(Si,Ri)c_i=(S_i, R_i)ci​=(Si​,Ri​) involves a subset of variables, Si=(xi1,xi2,…,xik)S_i=(x_{i_1}, x_{i_2}, \ldots, x_{i_k})Si​=(xi1​​,xi2​​,…,xik​​) (scope), and specifies the allowable combinations of values for those variables R⊆di1×⋯×dikR\subseteq d_{i_1} \times \dots \times d_{i_k}R⊆di1​​×⋯×dik​​(relation).

The goal is to find an assignment of values to the variables from their respective domains such that all constraints are satisfied simultaneously.

Formally, a solution to the CSP is an assignment A={x1=v1,x2=v2,…,xn=vn}A= \{x_1 = v_1, x_2 = v_2, \ldots, x_n = v_n\}A={x1​=v1​,x2​=v2​,…,xn​=vn​} such that:

  • Each variable xix_ixi​ is assigned a value viv_ivi​ from its domain DiD_iDi​.
  • For each constraint cic_ici​ involving variables (xi1,xi2,…,xik)(x_{i_1}, x_{i_2}, \ldots, x_{i_k})(xi1​​,xi2​​,…,xik​​), the combination of values (vi1,vi2,…,vik)(v_{i_1}, v_{i_2}, \ldots, v_{i_k})(vi1​​,vi2​​,…,vik​​) satisfies the constraint CiC_iCi​.

The CSP can be represented as a tuple ⟨X,D,C⟩\langle X, D, C \rangle⟨X,D,C⟩, where:

  • XXX is the set of variables.
  • D={d1,d2,…,dn}D = \{d_1, d_2, \ldots, d_n\}D={d1​,d2​,…,dn​} is the set of domains for the variables.
  • CCC is the set of constraints.

Note: An objective is optional. For example, sudoku is a CSP and has no objective! You just need to find a solution that satisfies the constraints

2. Cryptarithmetic

A cryptarithmetic puzzle is a mathematical exercise where:

  • The digits of some numbers are represented by letters (or symbols).
  • Each letter represents a unique digit.
  • The goal is to find the digits such that a given mathematical equation is verified
      OR
+     IS
+    FUN
--------
=   TRUE

This has 96 possible solutions. You should confirm that the two below are solutions!

      20
+     75
+    948
--------
=   1043

      60
+     37
+    928
--------
=   1025

Converting to a CSP Model

Variables

  • Based on the equation OR + IS + FUN = TRUE there are 8 variables.
  • The domain of each variable is {0,1,…,9}\{0,1,\dots, 9\}{0,1,…,9}.

Constraints:

  • OR + IS + FUN = TRUE
  • Each of the 8 letters is unique. Note this is called the all different constraint
  • O, I, F and T cannot be 0 (as we don't start numbers in decimal with a leading 0).

Note: There is no objective!

3. What is Job Shop Scheduling

It is quite common in manufacturing to have machines that perform a given task for a range of products.

A complete job may have a sequence of tasks that require the use of different machines, each with their own processing time.

History

  1. Early Development (1950s-1960s):

    • The job shop scheduling problem emerged in the context of manufacturing operations during the 1950s and 1960s.
    • Researchers began formalizing scheduling problems and exploring mathematical approaches to solve them.

  2. Algorithmic Development (1970s-1980s):

    • In the 1970s and 1980s, significant progress was made in developing algorithms to solve job shop scheduling problems.
    • Branch and bound algorithms were explored, along with mathematical programming techniques such as linear and integer programming.

  3. Heuristic Methods (1980s-Present):

    • From the 1980s onwards, heuristic methods gained popularity for solving job shop scheduling problems.
    • Heuristic algorithms, including genetic algorithms, simulated annealing, tabu search, and ant colony optimization, were developed to find approximate solutions efficiently.

  4. Exact Algorithms (1990s-Present):

    • In the 1990s and continuing into the present, research focused on developing exact algorithms for job shop scheduling.
    • Exact methods, such as branch and bound with dynamic programming and constraint programming, aim to find optimal solutions by exhaustively searching through all possible schedules.

  5. Hybrid Approaches and Applications (Present):

    • Current research in job shop scheduling emphasizes hybrid approaches that combine different algorithms and techniques to improve solution quality and computational efficiency.
    • Job shop scheduling has widespread applications across various industries, including manufacturing, transportation, healthcare, and services, where efficient resource scheduling is crucial for optimizing productivity and minimising costs.

Formal Definition

The job shop scheduling problem involves scheduling a set of n n n jobs on a set of m m m machines.

  • Each job consists of a fixed sequence of tasks
  • Each task must be processed on a specific machine.
  • The goal is to determine the optimal schedule for executing these predetermined sequences of tasks on the available machines in order to minimise the makespan.

Given:

  • nnn jobs: (J1,J2,…,Jn)( J_1, J_2, \ldots, J_n )(J1​,J2​,…,Jn​)
  • mmm machines: (M1,M2,…,Mm)( M_1, M_2, \ldots, M_m )(M1​,M2​,…,Mm​)
  • Each job JiJ_iJi​ has a sequence of tasks Ji=(ti1,ti2,…,tik)J_i = (t_{i1}, t_{i2}, \dots, t_{ik})Ji​=(ti1​,ti2​,…,tik​)
  • Each task tij=(Mk,pijk)t_{ij} = (M_k, p_{ijk})tij​=(Mk​,pijk​) where pijkp_{ijk}pijk​ is the processing time for task ijijij on machine kkk.

The objective is to find:

  • A schedule (Sijk)( S_{ijk} )(Sijk​) indicating the start time of task tijt_{ij}tij​ on machine MkM_kMk​

Such that:

  • Precedence: Each task is scheduled to start only after all preceding tasks for the same job have been completed (i.e. maintain the job sequence!).
    • Sijs+pijs≤SiktS_{ijs} + p_{ijs} \leq S_{ikt}Sijs​+pijs​≤Sikt​ (For job iii the start time for consecutive tasks ijijij and ikikik is such that task ij{ij}ij plus it's processing time on machine sss is less than the start time for task ikikik on machine ttt.)
  • No Overlap: A machine can only do one task at a time and must therefore finish a task before starting one.
    • Sijs+pijs≤SklsS_{ijs} + p_{ijs} \leq S_{kls}Sijs​+pijs​≤Skls​ or Skls+pkls≤SijsS_{kls} + p_{kls} \leq S_{ijs}Skls​+pkls​≤Sijs​ - Jobs on the same machine sss cannot overlap. Note this is two disjunctive (or) constraints, i.e. one must hold!
  • The total makespan, (Cmax)( C_{\text{max}} )(Cmax​) is minimised.
    • i.e. minimise the length of time from the earliest start time of the jobs to the latest end time.
