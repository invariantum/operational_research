# Timed in-class test: May 2026

The test is open book and lasts 4 hours. There are six questions worth 25 marks each, and the best four count.

**Questions:**
1. LP/integer production planning;
2. set covering;
3. transhipment;
4. help-desk simulation (SimPy);
5. forecasting (additive vs multiplicative);
6. flow-shop (Johnson) and job-shop (CP-SAT) scheduling.

## Before the test

1. Release revision material following **`open-book-materials-guidance.md`**:
   - practice papers and their *written* solutions: yes;
   - coded practice-paper solutions: only after the test;
   - nothing from this folder.
2. Prepare the room machines or student laptops with Anaconda. Students run
   **`student-setup/environment_check.ipynb`** on that machine (not on the course website). Pyomo + HiGHS,
   OR-Tools and SimPy must all print results. If one fails, install with
   `pip install pyomo simpy "ortools>=9.15,<9.16" "highspy>=1.11,<1.13"`.
3. Put `paper/in-class-test-2026-05.pdf`, `student-setup/submission-template.docx` and
   `student-setup/environment_check.ipynb` where students can download them.

## On the day

Follow **`invigilation-checklist.docx`** step by step:
1. Students download the files, without opening the paper.
2. They run the environment check, then restart the kernel.
3. Tell them what to submit.
4. They open the paper and begin.

Work goes in the submission template, with code and Excel files attached.

## After the test: marking

1. Copy **`marking/in-class-test-marking-grid-template.xlsx`** outside this folder. Row 1 holds each sub-part's
   maximum. Enter marks from row 3; question totals and the overall mark (best four) calculate automatically.
2. Check answers against **`solutions/worked-solutions.pdf`**.
3. To regenerate any number, run the code on your computer (it needs OR-Tools, so it doesn't work on the
   course website), from the top of the staff folder:
   ```
   python 03-in-class-test-2026-05/solutions/in_class_test_code.py      # all six questions
   ```
   Or, from inside `solutions/`: `import worked_solution_snippets as ws; ws.q3_results()`.
   The same solutions, step by step, are in `solutions/worked_solutions.ipynb`.
