# Practice Paper A (closest to the current test)

**Topics:**
1. linear programming;
2. binary/integer modelling;
3. minimum spanning tree;
4. Monte Carlo simulation;
5. forecasting (additive and multiplicative decomposition);
6. transhipment.

## Steps

1. Attempt **`practice-paper-a.pdf`** (4 hours, best four of six).
2. Mark it against **`practice-paper-a-solutions.pdf`**.
3. Run the reference code: **`practice_paper_a_code.ipynb`**. On the
   [course website](https://invariantum.github.io/operational_research/lab/index.html?path=Assignments/5cm522-operational-research-public/03-revision/practice-paper-a/practice_paper_a_code.ipynb),
   run the first cell, then *Run All*. On your computer, you can instead run `python practice_paper_a_code.py`.
   Either one prints every answer used in the written solutions.
4. Open the spreadsheets to follow the working cell by cell.
