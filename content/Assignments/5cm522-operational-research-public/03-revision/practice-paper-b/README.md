# Practice Paper B (closest to the current test)

**Topics:**
1. flow-shop scheduling (Johnson's rule);
2. job-shop scheduling;
3. maximum-coverage integer model;
4. SimPy queue simulation;
5. forecasting;
6. linear programming and transportation.

## Steps

1. Attempt **`practice-paper-b.pdf`** (4 hours, best four of six).
2. Mark it against **`practice-paper-b-solutions.pdf`**.
3. Run the reference code: **`practice_paper_b_code.ipynb`**. On the
   [course website](https://invariantum.github.io/operational_research/lab/index.html?path=Assignments/5cm522-operational-research-public/03-revision/practice-paper-b/practice_paper_b_code.ipynb),
   run the first cell, then *Run All*. On your computer, you can instead run `python practice_paper_b_code.py`.
   Either one prints every answer used in the written solutions.

The job-shop question uses Google OR-Tools (CP-SAT) when it is installed (on your computer, from
`environment.yml`). The browser has no OR-Tools, so there the code solves the same problem as a Pyomo + HiGHS
integer programme. Both give a makespan of 19 and the same schedule.
