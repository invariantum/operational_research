# Coursework Part A: linear and integer programming (25%, Semester 1)

## What you have to do

Answer the modelling questions in the brief and hand in one written report (graphical LP,
integer and binary models, solver output and interpretation). The report's presentation is marked
against the rubric in the brief's Appendix A.

## Steps

1. Read **`assessment-brief-part-a.pdf`**. It has the questions, submission date, format and marking rubric.
2. Solve each model by hand (graphical method), in Excel Solver, or in Python with Pyomo.
   Copy the starter model from
   [`../03-revision/templates/pyomo_starter_template.ipynb`](../03-revision/templates/pyomo_starter_template.ipynb).
   It runs on the course website, so you don't need to install anything.
3. Write the report and submit it as the brief describes.
