# Timed in-class test (50%, May)

**What it is about.** A 4-hour, open-book test on a computer: six questions, students answer any of them and
the **best four** count (25 marks each). Topics: linear and integer programming, set covering, transhipment,
queue simulation (SimPy), forecasting (additive vs multiplicative), and scheduling (Johnson's rule,
job shop). Notes, slides, tutorial material and their own code are allowed; **AI tools are not**.

**What a student hands in.** The completed `starter/submission-template.docx` (answers labelled as the
template asks), plus every Excel and Python file used, clearly labelled by question, uploaded to Course
Resources before the end time. Handwritten working may be scanned and added.

## Students: what to do, in order

| Step | When | Open | Do |
|---|---|---|---|
| 1 | Weeks before | [`revision/README.md`](revision/README.md) | Work through the practice papers in the order given there |
| 2 | Before the test day | `starter/environment_check.ipynb` (or `python starter/environment_check.py`) | Run it **on the computer you will use**: Pyomo + HiGHS, OR-Tools and SimPy must all print results. If not, install with `pip install -r ../requirements.txt` |
| 3 | Test day | `starter/submission-template.docx` | Download it with the paper; answer in it |
| 4 | Test day | `brief/in-class-test-2026-05.pdf` | Open only when told to |

The test needs a computer: Google OR-Tools (used for scheduling) has no browser version.

## Staff

### Before the test

1. Release revision material as set out in `staff/open-book-materials-guidance.md`: practice papers and their
   **written** solutions before the test; their **code** only after it; nothing from `brief/`, `solutions/` or
   `staff/` of this test. (This folder is public in the course repository, so publish the test's own files
   only after it has been sat.)
2. Students run `starter/environment_check.ipynb` on the machines they will use.
3. Put `brief/in-class-test-2026-05.pdf`, `starter/submission-template.docx` and
   `starter/environment_check.ipynb` where students can download them (the checklist uses OneDrive).

### On the day

Follow `staff/invigilation-checklist.docx` step by step: students download the files without opening the
paper, run the environment check, restart the kernel, hear what to submit, then open the paper and start.

### After the test: marking

1. Copy `staff/in-class-test-marking-grid-template.xlsx` outside this repository. Row 1 holds the maximum for
   each sub-part (each question totals 25); enter marks from row 3. Question totals and the overall mark
   (best four) calculate automatically.
2. Check answers against `solutions/worked-solutions.pdf`. To regenerate any number:

   | Where | How |
   |---|---|
   | Computer | `python solutions/in_class_test_code.py` (all six questions; the Q5 workbook goes to `solutions/output/`) |
   | Computer, one question | from `solutions/`: `import worked_solution_snippets as ws; ws.q3_results()` (`q1_results()` … `q6_results()`) |
   | Browser or Jupyter | `solutions/worked_solutions.ipynb`: the same solutions step by step |

   Questions: 1 LP/integer production plan, 2 set covering, 3 transhipment, 4 help-desk simulation (SimPy),
   5 additive vs multiplicative forecasting, 6 flow shop (Johnson's rule) and job shop (CP-SAT). Without
   OR-Tools (in the browser) Question 6 is solved as a Pyomo + HiGHS integer programme with the same makespan
   (18), the same schedule and the same "infeasible" result for the deadline-and-downtime variant.
