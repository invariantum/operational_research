\textbf{1. Linear Programming}

\textit{Source: Practice Paper A, original Question 1.}



Let $D$ be desks and $S$ be shelving units.

\begin{enumerate}
\item A suitable model is
\[
\max Z = 58D + 46S
\]
subject to
\[
5D + 3S \le 120
\]
\[
2D + 4S \le 96
\]
\[
S \ge 8
\]
\[
D,S \ge 0
\]

\item At the optimum, carpentry and finishing are both binding:
\[
5D+3S=120,\qquad 2D+4S=96
\]
Hence
\[
D=\frac{96}{7}\approx 13.71,\qquad S=\frac{120}{7}\approx 17.14
\]
Maximum contribution:
\[
Z=58D+46S=1584
\]

\item Binding constraints: carpentry and finishing.

Slack values:
\[
5D+3S=120 \Rightarrow 0 \text{ carpentry slack}
\]
\[
2D+4S=96 \Rightarrow 0 \text{ finishing slack}
\]
\[
S-8=\frac{64}{7}\approx 9.14
\]
So the minimum shelving requirement is not binding.

\item If shelving contribution rises to \pounds52, the objective becomes
\[
\max Z=58D+52S
\]
The optimal corner remains the same:
\[
\left(D,S\right)=\left(\frac{96}{7},\frac{120}{7}\right)
\]
with revised contribution
\[
Z=\frac{11808}{7}\approx 1686.86
\]
So the basis does not change.

\item The new condition is
\[
S \ge 0.3(D+S)
\]
which simplifies to
\[
3D-7S \le 0
\]
At the original optimum,
\[
\frac{S}{D+S}=\frac{17.14}{30.86}\approx 55.6\%
\]
so the original solution remains feasible. The optimal plan is unchanged.
\end{enumerate}

\textbf{2. Binary Integer Programming}

\textit{Source: Practice Paper A, original Question 2.}



Let $x_A,\ldots,x_F \in \{0,1\}$ where $x_i=1$ if project $i$ is selected.

\begin{enumerate}
\item A suitable model is
\[
\max B = 14x_A+17x_B+11x_C+20x_D+9x_E+15x_F
\]
subject to the budget constraint
\[
6x_A+8x_B+5x_C+9x_D+4x_E+7x_F \le 21
\]
and the logical constraints
\[
x_D \le x_B
\]
\[
x_A+x_F \le 1
\]
\[
x_C+x_E \ge 1
\]
\[
x_i \in \{0,1\}
\]

\item The optimal solution is
\[
x_B=x_D=x_E=1,\qquad x_A=x_C=x_F=0
\]
Total cost:
\[
8+9+4=21
\]
Maximum benefit:
\[
17+20+9=46
\]

\item Binary variables are needed because a project cannot be partly selected in any practical sense. A continuous LP could return fractional values such as ``0.4 of project $D$'', which would not be meaningful here.

\item Add
\[
x_A+x_B+x_C+x_D+x_E+x_F = 4
\]
There is no feasible solution satisfying all rules, the budget and the requirement to choose exactly four projects.

\item Example extension: allow projects to be staged over several years with different annual budgets and inter-year dependencies.
\end{enumerate}

\textbf{6. Transhipment}

\textit{Source: Practice Paper A, original Question 6.}



\begin{enumerate}
\item Use a network flow model with variables defined on the links of the network.

Let the node sets be:
\[
S=\{D_1,D_2,D_3\}, \qquad H=\{H_1,H_2\}, \qquad C=\{C_1,C_2,C_3,C_4\}
\]
and let the arc set be
\[
A=\{(i,h): i \in S,\ h \in H\} \cup \{(h,j): h \in H,\ j \in C\}.
\]

Let
\[
x_{uv}=\text{flow on arc }(u,v)\text{ for each }(u,v)\in A
\]
and let $k_{uv}$ be the corresponding unit transportation cost.

Objective:
\[
\min Z=\sum_{(u,v)\in A} k_{uv}x_{uv}
\]

Supply constraints for each depot $i \in S$:
\[
\sum_{h \in H} x_{ih} \le s_i
\]

Demand constraints for each clinic $j \in C$:
\[
\sum_{h \in H} x_{hj} = r_j
\]

Flow-balance constraints for each hub $h \in H$:
\[
\sum_{i \in S} x_{ih} - \sum_{j \in C} x_{hj} = 0
\]

Non-negativity:
\[
x_{uv} \ge 0 \qquad \text{for all } (u,v)\in A
\]

This is the same network-flow style used in Pyomo when variables are indexed over arcs and flow conservation is written at each transhipment node.

\textbf{8. Binary Integer Programming}

\textit{Source: Practice Paper B, original Question 2.}



\begin{enumerate}
\item Let $x_i=1$ if base $i$ is opened and 0 otherwise.
Let $y_j=1$ if district $j$ is covered and 0 otherwise.

\[
\max Z = 9000y_1+12000y_2+14000y_3+10000y_4+11000y_5+8000y_6
\]
subject to
\[
14x_A+11x_B+13x_C+10x_D+12x_E+9x_F \le 31
\]
\[
x_A+x_B+x_C+x_D+x_E+x_F \le 3
\]
\[
y_1 \le x_A+x_B
\]
\[
y_2 \le x_A+x_C+x_E
\]
\[
y_3 \le x_B+x_C+x_F
\]
\[
y_4 \le x_A+x_D+x_F
\]
\[
y_5 \le x_C+x_D+x_E
\]
\[
y_6 \le x_E+x_F
\]
\[
x_i,y_j \in \{0,1\}
\]

\item The optimal solution is
\[
x_A=x_C=1,\qquad x_B=x_D=x_E=x_F=0
\]
Total cost:
\[
14+13=27
\]
Covered districts:
\[
1,2,3,4,5
\]
Total covered population:
\[
9000+12000+14000+10000+11000=56000
\]

\item Yes. In the optimal solution above, district 6 remains uncovered. This is acceptable in a maximum-coverage model because the objective is to maximise covered population subject to tight resources. In a set covering model, complete coverage would be mandatory.

\item Revised model changes:

District 6 must be covered:
\[
y_6 = 1
\]
or equivalently
\[
x_E+x_F \ge 1
\]

Bases $B$ and $F$ cannot both be chosen:
\[
x_B+x_F \le 1
\]

Under these revised conditions, one optimal solution is
\[
x_E=x_F=1,\qquad x_A=x_B=x_C=x_D=0
\]
with covered districts $2,3,4,5,6$ and total covered population
\[
12000+14000+10000+11000+8000=55000
\]
There are multiple optimal solutions with the same covered population; for example, $x_C=x_F=1$ is also optimal.
\end{enumerate}

\textbf{11. Linear Programming}

\textit{Source: Practice Paper B, original Question 5.}



Let $C$ be casings and $I$ be inserts.

\begin{enumerate}
\item A suitable model is
\[
\max Z = 40C + 34I
\]
subject to
\[
4C + 2I \le 100
\]
\[
C + 3I \le 90
\]
\[
I \le 24
\]
\[
C,I \ge 0
\]

\item The optimal solution is
\[
C=13,\qquad I=24
\]
Maximum contribution:
\[
Z=40(13)+34(24)=1336
\]

\item Binding constraints: moulding and insert demand cap.

Slack values:
\[
4(13)+2(24)=100 \Rightarrow 0 \text{ moulding slack}
\]
\[
13+3(24)=85 \Rightarrow 5 \text{ assembly hours unused}
\]
\[
24-24=0
\]

\item The new condition is
\[
I \ge 0.25(C+I)
\]
which simplifies to
\[
C-3I \le 0
\]
At the original optimum,
\[
13-3(24)=-59 \le 0
\]
so the original solution remains feasible and optimal.

\item With 12 extra assembly hours, the assembly constraint becomes less restrictive, but the current solution already has 5 hours of assembly slack and is limited by moulding plus the insert cap. The optimal plan therefore does not change.

Extra contribution gained:
\[
0
\]
Maximum cost of buying all 12 hours:
\[
12 \times 3 = 36
\]
So the extra hours should not be bought.
\end{enumerate}
